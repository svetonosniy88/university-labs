Электронная
почта

Преимущества электронной почты по сравнению с обычной:
  1. Почти мгновенная скорость доставки.
  2. Минимальная вероятность пропажи письма.
  3. Высокая информативность при ответе.
  4. Возможность защиты информации.
  5. Возможность прилагать к письму любые виды компьютерных файлов.
  6. В процессе передачи информация не искажается.
  7. Удобство хранения архива писем.
Недостатки электронной почты:
  1. Большое количество спама - непрошенных рекламных объявлений.
  2. Письма с вирусами и "троянскими конями".
  3. Опасность потерять сразу весь архив писем.
  4. Подделка имени отправителя.
