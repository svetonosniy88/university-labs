# Лабораторные работы

Общий репозиторий лабораторных и практических работ по университетским дисциплинам.

## Структура

| Папка | Дисциплина |
| --- | --- |
| `python_labs` | Программирование на Python |
| `cpp_yasp_labs` | Языки системного программирования, C++ |
| `cpp_dsa_labs` | Структуры данных и алгоритмы, C++; общее решение `cpp_dsa_labs.slnx`, библиотека `flist`, отдельные проекты лабораторной и ДЗ |
| `csharp_labs` | Программирование на C# |
| `web_layout_labs` | Основы web-вёрстки |

Условия, исходный код и сопроводительные материалы каждой работы размещаются внутри соответствующей папки дисциплины.

В `web_layout_labs` работы 1–3 открываются через `Оглавление.html` в папке «Практические работы 1–3 — HTML». Работы 4–7 используют общий сайт. Его точка входа — `Valorant.html` в папке «Практические работы 4–7 — сайт VALORANT».
