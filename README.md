# Лабораторные работы

Общий репозиторий лабораторных и практических работ по университетским дисциплинам.

## Структура

| Папка | Дисциплина |
| --- | --- |
| `python_labs` | Программирование на Python |
| `cpp_yasp_labs` | Языки системного программирования, C++ |
| `cpp_dsa_labs` | Структуры данных и алгоритмы, C++ |
| `csharp_labs` | Программирование на C# |
| `web_layout_labs` | Основы web-вёрстки |

Условия, исходный код и сопроводительные материалы каждой работы размещаются внутри соответствующей папки дисциплины.
