# Исходные материалы занятия

Выданные пользователем 9 октября 2026 года `FLIST.h`, `FLIST.cpp`, `Source.cpp` скопированы из `Downloads/Telegram Desktop` **без изменения байтов**. `Source.cpp` использует Windows-1251; если комментарии не читаются, открыть в Visual Studio с этой кодировкой. Рабочие файлы проектов используют UTF-8.

`FLIST` — контейнер в пространстве имён `flist` со служебной головой. Подключаемая копия находится в `../../flist`; её исправления описаны в README библиотеки.

`Source.cpp` содержит материал занятия, ранний глобальный тип `NODE`, несколько упражнений и `main`. Он сохранён для разбора и виден среди элементов общего решения, но не включён в компиляцию приложений. Глобальные `NODE*` и `flist::NODE*` — разные типы; их нельзя взаимозаменять.

Этот снимок не является готовым набором проверенных решений: например, в `find_last_ver2` нет продвижения указателя внутри цикла. Рабочие семь рекурсивных функций находятся в `../../homework/recursive_tasks.cpp`.
