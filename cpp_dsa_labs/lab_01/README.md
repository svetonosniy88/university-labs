# DSA_space

Открыть `DSA_space.slnx`, выбрать `Debug | x64` или `Release | x64`, запустить **Ctrl+F5**. Все текущие библиотеки и задания находятся в одном проекте `DSA_space`; отдельных проектов для стеков, очереди и второй лабораторной нет.

## Меню

| Пункт | Задание | Вход | Результат |
| --- | --- | --- | --- |
| 1 | Прежняя лабораторная: перенос первой группы из двух и более нечётных узлов после сортировки | По умолчанию `input.txt` | Консоль и `output.txt` |
| 2 | Лабораторная № 2, задание № 12: все слова максимальной длины | Например, `words.txt` | `output.txt` |
| 3 | Баланс скобок через `StackL` | Например, `brackets.txt` | Консоль: строка, `->`, `Yes` или `No` |
| 4 | Та же проверка через `StackA` | Например, `brackets.txt` | Тот же формат |
| 0 | Выход | — | — |

После выбора программа запрашивает входной файл. Пустой ввод означает `input.txt`. При ошибке открытия можно ввести другое имя. Для пунктов 1 и 2 результат перезаписывается в `output.txt` в рабочей папке проекта. Ввод из этого же файла, в том числе через другой путь или жёсткую ссылку, отклоняется. Пункты 3 и 4 этот файл не изменяют. После выполнения или ошибки программа возвращается в меню; конец консольного ввода завершает работу.

## Исходники

- `main.cpp` — меню, открытие файлов и вывод.
- `Tasks.h`, `Tasks.cpp` — прежние `find` и `task15`, функция `task12`, подсчёт длины слова и общий предикат `balanced`.
- `Stack.h`, `Stack.cpp` — две самостоятельные библиотеки стека: `StackL` и `StackA`.
- `Queue.h`, `Queue.cpp` — очередь `QueueL` для слов.
- `../flist/FLIST.h`, `../flist/FLIST.cpp` — прежняя общая библиотека списка. Исходник включён прямо в этот проект; второй копии нет.
- `words.txt`, `brackets.txt` — небольшие примеры для новых заданий. Прежний `input.txt` сохранён.

## Лабораторная № 2: задание 12

Требуется вывести **все слова максимальной длины во всём файле**, каждое с новой строки, в исходном порядке. Повторяющиеся слова сохраняются. Для номера 12 очередь выбирается по `12 % 3 == 0`: односвязный список.

`task12(input, words)` читает слова и хранит только текущие максимумы. При более длинном слове прежняя очередь очищается; при равной длине слово добавляется в хвост. Более короткие слова пропускаются. Функция возвращает максимальную длину, ввод и вывод остаются в `main.cpp`.

Для `words.txt` результат:

```text
notebook
computer
notebook
```

Пустой файл или одни пробелы дают пустой `output.txt`. Чтение пропускает любое количество пробельных символов; знаки препинания из слов не удаляются. Файлы с русским текстом следует сохранять в UTF-8. `word_length` считает начала UTF-8-символов, а не байты: байты продолжения имеют старшие биты `10` и не увеличивают счётчик. UTF-8 BOM в начале файла удаляется. Предполагается корректный текст UTF-8; проверка повреждённой кодировки в задачу не входит.

## Библиотеки

`StackInfo = char`, `QueueInfo = std::string`: стек хранит скобки, очередь — слова. Готовые `std::stack` и `std::queue` не используются. Узлы скрыты внутри классов, новых пространств имён нет.

| Класс | Представление | Основные операции |
| --- | --- | --- |
| `StackL` | Список без служебной головы; вершина `head`, счётчик `count` | `empty`, `top`, `push`, `pop`, `size` |
| `StackA` | Динамический массив фиксированной вместимости; `head = -1` при пустоте | Те же операции и `full` |
| `QueueL` | Список без служебной головы; `head`, `tail`, `count` | `empty`, `front`, `back`, `push`, `pop`, `size`, `view` |

Конструкторы создают пустые контейнеры, деструкторы освобождают память. Поверхностное копирование запрещено. `show` у обоих стеков закрыт; `view` у очереди публичен по примеру занятия 27 октября. После удаления последнего узла очереди оба указателя равны `nullptr`; очередь можно снова использовать.

Пустые `pop`, `top`, `front`, `back` выводят диагностическое сообщение. Возвращающие значение методы при ошибке дают инициализированное пустое значение: `char{}` или пустую строку. Это не элемент контейнера: клиент обязан сначала проверить `empty()`. Полный `StackA` отклоняет добавление, не изменяя состояние. Явных исключений в контейнерах нет; ошибки выделения памяти перехватываются главным циклом программы.

## Проверка скобок

Открывающая скобка помещается в стек. Закрывающая должна соответствовать вершине; после проверки вершина удаляется. В конце стек должен быть пуст. Остальные символы игнорируются. Для каждой строки создаётся новый стек.

`balanced` — одна небольшая шаблонная функция для двух классов с одинаковым публичным интерфейсом. Она получает пустой стек; в массиве должно хватать места для всех открывающих скобок. В программе вместимость `StackA` выбирается по длине строки и затем не меняется. Поэтому ограничение вместимости не превращает правильную длинную строку в ложное `No`.

## Проверки

Обе конфигурации собираются в `../build/x64/<конфигурация>/DSA_space/`. Для установленного инструментария выбран нативный компилятор x64; отдельный каталог сборки исключает смешивание старых файлов `lab_01` с `DSA_space`.

- `../tests/containers_tests.cpp` — операции контейнеров, сравнение со стандартными моделями только в тесте, скобки, UTF-8, длинные слова и прежняя задача № 15. Пройдено 105 288 проверок с AddressSanitizer.
- `../tests/check_space.py` — 131 проверка меню и файловых сценариев в Debug и Release.
- `../tests/check_scenarios.py` — 42 проверки прежней лабораторной и рекурсивного ДЗ; запуск первой работы адаптирован к общему меню.

Тестовые файлы находятся в `../build/`; рабочие `input.txt`, `output.txt` и данные рекурсивного ДЗ не перезаписываются проверками. Готовность исходников не означает приёмку преподавателем.
