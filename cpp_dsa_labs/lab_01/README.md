# Лабораторная работа № 1

Консольное приложение с восстановленным на занятии прототипом библиотеки для односвязного списка.

Сохранены канонические обозначения из учебного варианта:

- тип указателя `ptrNODE`;
- изменяемый указатель `ptr`;
- временный указатель `tmp`;
- функции `init`, `empty`, `add_by_pointer`, `add_to_head`, `add_after`, `del_by_pointer`, `del_from_head`, `del_after`, `print` и `clear`;
- построение списка как стека, очереди и упорядоченного списка;
- учебная задача с дублированием нечётных элементов.

В демонстрационном запуске числа читаются из `data.txt`, список строится как стек, затем все нечётные элементы дублируются.

Это рабочая основа первой лабораторной по однонаправленным спискам. Для неё назначено задание № 15; точная формулировка задания пока не сохранена и должна быть добавлена до реализации прикладной части.

Вариант № 4 с проверкой формулы относится к более поздней работе по стекам и очередям и не является следующим этапом этой лабораторной.
