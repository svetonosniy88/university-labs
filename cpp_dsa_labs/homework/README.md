# Домашняя работа — рекурсивная обработка списка

Отдельный консольный проект `homework` в общей среде СДиА. Решения семи задач перенесены из `lab_01/main.cpp`, версия `51634a1`, и адаптированы к контейнеру `flist::FLIST` со служебной головой.

Открыть `homework.slnx` либо общее решение `../cpp_dsa_labs.slnx`, выбрать `homework` запускаемым проектом, платформу `x64` и нажать **Ctrl+F5**. `data.txt` содержит исходные числа; пример повторяет прежний массив `3 1 5 1 4 1`. Рабочая папка задана как папка проекта.

- `main.cpp` — чтение из файла, проверка пустоты и демонстрация операций.
- `recursive_tasks.h/.cpp` — семь рекурсивных функций: максимум, обратный вывод, замена всех вхождений, удаление первого, дублирование первого, дублирование всех на выходе из рекурсии, проверка строгого возрастания.
- Общие вставка, удаление, построение и освобождение находятся в `../flist`.

Функции над элементами принимают существующий реальный узел. Сначала проверять `list.empty()`, затем передавать `list.get_head()->next`. Максимум пустого списка не определяется; служебный ноль в него не включается. Пустой список можно безопасно прочитать и вывести, но рекурсивные функции для него не вызываются.

`delete_first(list, before, elem)` принимает **предшественника** реального узла; первоначально передают `list.get_head()`. Удаление выполняется через `list.erase_after(before)`, поскольку `del_by_pointer` закрыт. После удаления единственного узла снова проверять пустоту перед дальнейшими элементными операциями.

Для дублирования передаётся контейнер по ссылке и реальный узел; вставка выполняется через `list.insert_after`. `duplicate_all` сначала обрабатывает хвост, затем вставляет копию: вновь созданные узлы в рекурсивный обход не попадают. Это вставка копии элемента, а не умножение его значения на два.

`replace_all` отдельно вызывает рекурсию и лишь затем объединяет признаки через `||`, поэтому замена в голове не пропускает хвост. Возвращаемый признак означает, что встретился хотя бы один заменяемый элемент, в том числе при одинаковых старом и новом значениях. Строгое возрастание требует `<`, равные соседи дают `false`.

Демонстрационный `main` последовательно изменяет один список, как прежний код; каждую функцию можно вызывать отдельно для своего задания. Исходный `Source.cpp` из занятия сохранён в `../materials/2026-10-09/` как материал и не компилируется в этом проекте.
